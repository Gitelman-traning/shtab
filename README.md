# Штаб

Центр компании: единая витрина показателей и сайт с разделами подразделений поверх неё.

Три слоя:

1. **Сборщики** (`collector/`) — ночные скрипты складывают точки показателей в витрину через `POST /api/ingest`.
   Раскладка источников (таблицы, колонки) не хранится в коде — приходит в переменных окружения.
2. **Витрина** (`schema.sql`, Cloudflare D1) — одна запись: показатель, период, срез, факт; планы — рядом.
   Реестр показателей — `metrics.json`.
3. **Сайт** (`site/`, Cloudflare Pages + Functions) — API витрины, общий экран и разделы с персональными логинами.

API (нужен токен сборщика или сессия):

- `POST /api/ingest` — пачка точек, идемпотентно
- `GET /api/points?metric=a,b&ptype=day&from=&to=&dim=` — точки
- `GET /api/metrics`, `POST /api/metrics` — реестр
- `GET /api/status` — прогоны и покрытие

Документы, раскладка и настройка — в приватном репозитории.

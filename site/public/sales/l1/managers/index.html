По неделям лид → проведённая встреча по каждому менеджеру, 8 недель + текущая

Лид — сделка Первой линии по дате «вступил в чат», назначено — «встреча назначена», проведено — «встреча проведена» в той же сделке; менеджер — ответственный по сделке Первой линии. Действия — записи из журнала событий amoCRM, авторство которых закреплено за менеджером, за день. Звонки — из выгрузки АТС по ответственному, только состоявшиеся.
